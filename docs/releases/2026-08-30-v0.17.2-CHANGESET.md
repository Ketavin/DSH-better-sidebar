## Deep-review finding-to-fix map

1. **Packaged ConPTY fix was missing.** The old root `pnpm-workspace.yaml` patch did not travel with `pnpm pack`; a clean consumer silently received unpatched node-pty. The candidate now owns `scripts/conpty-console-list-agent.cjs` plus `src/windows-pty-cleanup.ts`, installs the hook on both user and agent PTYs, and carries no workspace patch.
2. **Pinned-terminal session isolation was fail-open.** Missing cwd values exposed workspace pins too broadly and stale local activation could override the next session's real active tab. Both paths now fail closed and Windows/UNC/POSIX workspace identity is normalized explicitly.
3. **Pinned terminals had unbounded client resources.** Every inactive virtual projection mounted xterm and a WebSocket. Only the active projection now mounts; the home-session PTY remains authoritative and parked.
4. **Viewer HMR missed same-id replacements.** Registry snapshots based only on sorted ids could not observe dispose/register of a new descriptor with the same id. Every registry mutation now advances a monotonic React revision.
5. **Terminal link ranges used UTF-16 offsets.** Links after or containing CJK, emoji, combining sequences, and wide cells could point at the wrong xterm columns. The provider now maps URL offsets through xterm cell widths.
6. **Release identity and publishing were unsafe.** Package, manifest, service, tag, artifact and workflow are aligned at `0.17.2`; releases in forks build/test/dry-run only and cannot attempt the upstream npm trusted-publisher identity.
7. **Windows named signals could throw asynchronously.** node-pty may defer `kill('SIGKILL')` until ConPTY becomes ready, outside the caller's `try/catch`. Windows now calls parameterless `kill()` directly; POSIX retains named signals.
8. **Unrelated registry changes could destroy unsaved drafts.** `EditorHost` previously reloaded on every tab or viewer registration. A dedicated monotonic viewer-registry subscription now ignores tab changes and defers viewer re-matching while the current editor is dirty, saving, or failed.
9. **Persisted pins were invisible after a cold start.** The store now performs one bounded localStorage scan, retaining only sanitized sessions that actually contain pinned terminals. Ordinary conversation history is not mirrored into memory.
10. **Forward-slash `//` paths weakened workspace isolation.** Without a host-platform signal they are now treated as case-sensitive; explicit drive and backslash-UNC paths retain Windows case-insensitive semantics.
11. **Windows validation and resource use were under-specified.** CI now has a real Windows ConPTY lane. Local Windows full-suite forks are capped at two, preventing the unbounded short-lived Node worker burst observed during review while retaining native-process isolation.
12. **Manual release dispatch could silently do nothing.** Every manual dispatch is now validation-only; npm publishing remains possible only for a published release in the canonical upstream repository.
13. **Windows PTY teardown could enqueue duplicate kills and strand a test worker.** A terminating signal followed by close could queue two kills before ConPTY became ready. Termination is now idempotent, async owners can await all exit notifications, and the real Windows lane completes normally instead of timing out after successful assertions.
