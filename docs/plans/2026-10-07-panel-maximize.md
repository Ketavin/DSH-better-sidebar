# 面板最大化

用户可从右/底面板的标签栏最大化，并恢复原宽度/高度。该状态只存在当前会话的 Sidebar 组件，不进入持久化 schema。最大化改变原节点的几何和宿主内部层级，不 portal、不搬移标签、不重新挂载 Workbench；切换尺寸时浏览器实例、终端、输入草稿和连接保持。

宿主层继续使用 `data-dsh-panel-host` 的 z-index 25，最大化面板在其内部为 44，低于宿主插件审批面（30）和全局浮层（100/1000）。所有颜色沿用 DSH 令牌。最大化时不改主对话推挤变量，恢复无需回写尺寸。普通区域 Esc 可恢复；网页键盘、编辑器和 IME 的 Esc 不被截获。

验收覆盖原尺寸不变、原 DOM 和组件实例保留、Esc 的编辑/IME 边界及实际浏览器几何。

最大化期间隐藏原布局的折叠按钮簇，避免右面板移到视口右缘后，原按钮簇遮挡恢复按钮；恢复后按钮簇和尺寸拖拽一并还原。关闭面板清除临时最大化状态，重新打开使用原尺寸。
