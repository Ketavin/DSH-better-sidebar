Before formal promotion, rollback is simply: keep the release draft, revert or close PR #2, and retain formal `0.16.1` unchanged.

If a later formal promotion fails:

1. Stop only the newly promoted 3080 process.
2. Restore the formal profile dependency to `file:packages\\release\\dsh-better-sidebar-0.16.1.tgz`.
3. Restore the pre-promotion `package.json`, `pnpm-lock.yaml` and package artifact from the timestamped rollback directory.
4. Run the profile's frozen install command.
5. Start the formal web process on 3080 with the existing wrapper and environment.
6. Verify the formal artifact SHA-256 above, `GET /`, Finance registration and terminal open/close.
7. Do not touch Gateway 8002 unless independent evidence identifies it as the fault domain.
